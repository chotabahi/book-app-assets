# 📚 BookStore App — Static Assets & CDN Repository

![CDN](https://img.shields.io/badge/CDN-jsDelivr-orange?style=flat-square&logo=jsdelivr)
![License](https://img.shields.io/badge/License-MIT-blue?style=flat-square)
![Status](https://img.shields.io/badge/Status-Active-success?style=flat-square)

This repository serves as the centralized static asset host and Content Delivery Network (CDN) endpoint for the **BookStore Application** (Aptech eProject submission). It provides global high-speed image distribution for book covers, category banners, and store media.

---

## 🌐 Production CDN Endpoint

Assets are served globally via **jsDelivr CDN** directly from the `main` branch:

`https://cdn.jsdelivr.net/gh/chotabahi/book-app-assets@main/[FOLDER]/[FILENAME]`

### Base URL
`https://cdn.jsdelivr.net/gh/chotabahi/book-app-assets@main/`

## 🔄 Updating Firestore URLs (`update-cdn-urls.js`)

Maintenance script that rewrites the `coverUrl` / `imageUrl` fields in the app's Firestore `books` and `categories` collections to point at the CDN links above.

1. Download a service account key from Firebase Console → Project settings → Service accounts, and save it as `serviceAccountKey.json` in this folder. It is git-ignored, so never commit it.
2. Run:
   ```bash
   npm install
   node update-cdn-urls.js
   ```
